# Tasks

Aqui van planes de ejecucion aterrizados desde una feature o decision.

## Contenido Esperado

- objetivo de implementacion;
- alcance concreto;
- archivos o modulos afectados;
- pasos de trabajo;
- validaciones;
- riesgos;
- pendientes.

## Relacion con Otras Carpetas

- la motivacion viene de `../features`;
- las decisiones salen de `../decisions`;
- el contexto base vive en `../current-state`.
