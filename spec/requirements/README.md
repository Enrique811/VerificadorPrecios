# Requirements

Aqui van los requerimientos base del producto o del sistema.

## Contenido Esperado

- objetivos de negocio;
- restricciones tecnicas;
- criterios de aceptacion globales;
- reglas operativas o regulatorias;
- dependencias externas.

## Sugerencia

Crear un archivo por bloque de requerimientos, por ejemplo:

- `core-pos.md`
- `impresion-etiquetas.md`
- `licenciamiento.md`
