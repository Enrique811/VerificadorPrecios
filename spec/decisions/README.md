# Decisions

Aqui se registran decisiones tecnicas o funcionales con impacto duradero.

## Cuando Crear una Decision

- cambio de arquitectura;
- cambio de libreria o dependencia;
- cambio de formato de datos;
- cambio de integracion con impresoras o reportes;
- regla tecnica que conviene preservar.

## Formato

Usar la plantilla `../templates/adr.md`.
